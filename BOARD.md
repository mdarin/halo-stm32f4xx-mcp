## 🎯 Текущая задача

### Задача #1: Парсинг PDF документации через Marker
**Статус:** 🟡 В процессе  
**Приоритет:** Критичный путь  
**Срок:** 2-3 дня  
**Связь с TASK.md:** Фаза 0, Шаг 0.1

**Цель:** Конвертировать RM0090, Datasheet F407, Errata Sheet из PDF в Markdown для последующей индексации в Qdrant.

**Почему это важно:**
- Качество RAG на 90% определяется качеством MD-чанков
- Без документации агент не сможет отвечать на вопросы о регистрах
- Marker автоматически извлекает таблицы, заголовки, код

**Пункты для реализации:**

- [ ] **1.1 Установить Marker**
  ```bash
  pip install marker-pdf
  marker_single --help  # Проверить установку
  ```

- [ ] **1.2 Подготовить PDF файлы**
  - [ ] Скачать RM0090 (Reference Manual, ~2000 стр.)
  - [ ] Скачать DM00037053 (Datasheet F407, ~150 стр.)
  - [ ] Скачать ES0113 (Errata Sheet, ~100 стр.)
  - [ ] Разместить в `docs/source_pdf/`

- [ ] **1.3 Конвертировать RM0090**
  ```bash
  marker_single docs/source_pdf/RM0090.pdf docs/reference_manual/ --workers 4
  ```
  - [ ] Проверить результат (~200-300 MD файлов)
  - [ ] Выборочно проверить 5-10 страниц (таблицы регистров, диаграммы)
  - [ ] Зафиксировать проблемы качества (если есть)

- [ ] **1.4 Конвертировать Datasheet F407**
  ```bash
  marker_single docs/source_pdf/DM00037053.pdf docs/datasheet_f407/ --workers 4
  ```
  - [ ] Проверить pinout таблицы
  - [ ] Проверить memory map

- [ ] **1.5 Конвертировать Errata Sheet**
  ```bash
  marker_single docs/source_pdf/ES0113.pdf docs/errata/ --workers 4
  ```
  - [ ] Проверить список известных багов F407

- [ ] **1.6 Написать вручную `f407_known_issues.md`**
  - [ ] CCM RAM + DMA несовместимость
  - [ ] NVIC Priority Grouping (обычно 4)
  - [ ] USB/SDIO требуют 48 MHz
  - [ ] Таймеры APB1/APB2 умножают частоту (x2/x4)
  - [ ] Добавить в `docs/hardware_pitfalls/`

- [ ] **1.7 Создать тестовые MD файлы (3-5 шт.)**
  - [ ] `docs/reference_manual/gpio.md` — для отладки RAG
  - [ ] `docs/reference_manual/tim1.md` — для отладки RAG
  - [ ] `docs/reference_manual/dma.md` — для отладки RAG
  - [ ] Добавить YAML frontmatter вручную (peripheral, register, chapter)

- [ ] **1.8 Проверить качество**
  - [ ] Открыть 10 случайных MD файлов
  - [ ] Проверить таблицы регистров (битовые поля, адреса)
  - [ ] Проверить перекрёстные ссылки
  - [ ] Зафиксировать проблемы в `docs/QUALITY_ISSUES.md`

**Критерии готовности:**
- ✅ Marker установлен и работает
- ✅ Все 3 PDF конвертированы в MD
- ✅ `f407_known_issues.md` написан вручную
- ✅ 3-5 тестовых MD файлов готовы для RAG
- ✅ Качество проверено, проблемы зафиксированы

**Результат:**
- Директория `docs/` с ~300 MD файлами
- Готово к индексации в Qdrant (Следующая задача: `index_docs.py`)
