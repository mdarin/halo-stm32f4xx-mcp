# Ingestion в Qdrant — короткая инструкция

Источник: `rm0090_sections/` (428 .md + `manifest.json`).

1. **Чанк = файл** (уже порезан; медиана ~1200 токенов). Файлы >30 КБ (10 шт.) — доп. чанкование 500–1000 токенов, перекрытие 10–15%, резать по `###`.
2. **Metadata чанка** — копия полей `manifest.json` по имени файла:
   `chapter`, `section`, `title`, `source_file`, `applies_to`, `not_on_f407`.
3. **Фильтр поиска**: `must_not: [{key: "not_on_f407", value: true}]` — отсекает главы F42x/43x (73 файла: RCC-вариант, DMA2D, DCMI, LTDC, SAI, FMC).
4. **`INDEX.md`** индексировать отдельным документом (`type: "index"`, без not_on_f407-фильтра) — маршрут «задача → глава» для агента.
5. Embedded текст: тело файла как есть; шапка `> [RM0090 ch.N §N.M]` уже внутри чанков `__c*` — не удалять.
